# @somesass/vscode-css-languageservice

This is a fork of vscode-css-languageservice with additions to support the language features in [@somesass/language-services](https://www.npmjs.com/package/@somesass/language-services/). It's kept as a separate module to make it easier to sync changes from and contribute back to upstream.

You probably want `@somesass/language-services`.
